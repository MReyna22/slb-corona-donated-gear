## Reset and installation

1. The retained Dell preboot result reports **All tests passed successfully**, code **2000-0000**. Individual coverage, duration and extended-test selection are not established by that screen.
2. Following the confirmed erase authorization, Dell Security Manager displayed **Data Wipe Completed Successfully**. This records firmware-reported success, not independent forensic validation.
3. The installer initially showed only the USB, with the internal SSD absent. The earlier BIOS baseline was RAID On. After AHCI/NVMe guidance, the next image showed **Disk 0 Unallocated Space 953.9 GB**, matching the internal SSD. The changed BIOS mode was not separately photographed, so the final mode is not asserted.
4. Installation reached first-time setup, then normal Settings as PC-003.
5. Activation shows Windows 11 Home **Active**; Windows Update later shows **You're up to date**. An offered preview-update build during download does not establish the installed build.

A disk wipe does not independently establish removal of cloud registrations or firmware management. No enrollment bypass is claimed. Earlier BIOS Absolute enablement does not establish an active subscription or current monitoring.

## Baseline and later observations

Privately reviewed pre-reset BIOS photos showed UEFI boot, Secure Boot On / Deployed Mode, Intel PTT On, virtualization/VT-d and preboot/OS kernel DMA support enabled. These settings do not establish runtime OS protection or successful VM workloads. Explicit BIOS password set/not-set status was not visible.

WLAN was disabled in the pre-reset baseline. Later Windows evidence detects AX211 and shows a connection and loaded webpage. A new BIOS after-state image was not supplied. The photo and operator report support basic Wi-Fi connection/browsing, not measured throughput, actual radio band/channel width or independently isolated egress.

Intel Tile Device remains listed under Other devices. Its opened Properties window reported **Code 45: not connected** before later screenshots. This is a non-present-device status, not by itself a missing-driver or hardware-failure diagnosis. Properties was not reopened after updates.
