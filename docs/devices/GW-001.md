# GW-001 — UniFi Security Gateway

**Equipment:** Donated Ubiquiti USG-3P  
**Project:** [USG Revival](https://github.com/MReyna22/USG-Revival)  
**Validation date:** October 4, 2026  
**Status:** OpenWrt revival and basic wired routing validation completed

The original internal USB was imaged and verified before reuse. With no spare USB available, I reused the stock drive after preserving the original image privately. OpenWrt 25.12.5 booted successfully, and the hostname survived a restart. I changed the admin password, confirmed a fresh login, and saved a configuration archive outside the public repositories.

PC-001 served as the wired LAN client with Wi-Fi disabled. Observed results include a 1 GbE LAN link, a WAN DHCP lease, four successful internet ping replies with no loss, DNS resolution through the USG, and a successful browser page load. The visible firewall zone policies were reviewed; inbound enforcement and throughput were not tested.

The [project documentation](https://github.com/MReyna22/USG-Revival/tree/main/docs) and [reviewed evidence index](https://github.com/MReyna22/USG-Revival/tree/main/evidence) contain the installation decisions, hashes, screenshots, and validation limits. Device identifiers, home-network details, raw USB images, OEM binaries, and configuration backups remain private.

This records GW-001's actual use in the revival project. Broader home-network deployment remains separate. The dated inventory CSV is an initial baseline; the working Google Sheet is not automatically synchronized with these project records.
